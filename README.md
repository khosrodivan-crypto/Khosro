# ولتا (VOLTA) — راهنمای نصب و استفاده

فروشگاه قطعات کامپیوتر **ولتا (VOLTA)** با اسمبل هوشمند، پنل مدیریت و ثبت سفارش.

> شعار: «جریانِ درستِ سخت‌افزار» — تأسیس ۱۳۹۲ — دامنه: `volta-pc.ir`

## ۱) ساختار فایل‌ها

```
index.html          صفحه اصلی (اسلایدر، دسته‌ها، تخفیف‌ها، محبوب‌ها، برندها)
shop.html           فهرست محصولات با فیلتر (cat / q / brand / deal / sort / page)
product.html        جزئیات محصول  →  product.html?id=cpu-i7-14700k
build.html          اسمبل هوشمند (با لینک اشتراکی b=...)
track.html          پیگیری سفارش با کد
about.html          داستان و تاریخچهٔ برند ولتا
admin.html          پنل مدیریت
css/main.css        استایل فروشگاه
css/admin.css       استایل پنل مدیریت
js/seed.js          کاتالوگ و تنظیمات اولیه (فقط بار اول استفاده می‌شود)
js/core.js          هسته: API، سبد خرید، هدر/فوتر، کارت محصول، تسویه
js/home.js shop.js product.js build.js admin.js   منطق هر صفحه
img/                تصاویر محصولات و بنرها (webp)
fonts/              فونت شبنم
data.php            ذخیره/خواندن داده روی سرور (JSON + قفل فایل)
auth.php            ورود مدیر (شماره + رمز) و توکن ۷ روزه
upload.php          آپلود تصویر (نیازمند توکن مدیر)
config.php          تنظیمات حساس: شماره و رمز مدیر، کلیدها، درگاه
data/               داده‌های سایت (به‌صورت خودکار ساخته می‌شود؛ از وب بسته است)
uploads/            تصاویر آپلودشده
```

## ۲) پیش‌نیاز هاست

- PHP نسخه ۷.۴ تا ۸.۴ (بدون نیاز به mbstring)
- دسترسی نوشتن (۷۵۵) روی پوشه‌های `data/` و `uploads/`
- Apache با `mod_rewrite` (فایل `.htaccess` آماده است). برای Nginx معادل این دو قاعده را اضافه کنید:
  - `location ^~ /data/ { deny all; }`
  - `location ^~ /uploads/ { location ~ \.php$ { deny all; } }`

## ۳) نصب در ۴ قدم

1. همهٔ فایل‌ها را در `public_html` آپلود کنید (پوشهٔ `data` و `uploads` خالی و قابل نوشتن باشند).
2. آدرس سایت را باز کنید. فروشگاه با کاتالوگ نمونه نمایش داده می‌شود (داده‌ها موقتاً از `js/seed.js` خوانده می‌شوند).
3. وارد `admin.html` شوید با **همان شمارهٔ مدیر و رمز قبلی** (در `config.php` تعریف شده‌اند).
   در اولین ورود، کاتالوگ نمونه به‌صورت خودکار روی سرور نوشته می‌شود و از آن به بعد فقط از پنل قابل ویرایش است.
4. در تب «تنظیمات»، نام فروشگاه، تلفن‌ها، آدرس، سقف ارسال رایگان، شماره کارت و شبکه‌های اجتماعی را بررسی کنید.

## ۴) پنل مدیریت (`admin.html`)

| تب | کاربرد |
|---|---|
| داشبورد | آمار محصولات، موجودی، سفارش‌های در انتظار، فروش تأییدشده، پرفروش‌ها |
| محصولات | افزودن/ویرایش/کپی/حذف، روشن‌وخاموش کردن نمایش، جستجو و فیلتر |
| تخفیف‌ها | تعیین درصد تخفیف با یک عدد، حذف تخفیف |
| سفارش‌ها | جزئیات سفارش، تأیید/لغو/حذف، خروجی CSV |
| دسته‌بندی‌ها | نام، نام کامل، آیکون، ترتیب، فعال/غیرفعال |
| اسلایدر | ویرایش ۳ اسلاید صفحهٔ اصلی |
| تنظیمات | اطلاعات تماس، ارسال، پرداخت، اطلاع‌رسانی |
| گزارش و بایگانی | فروش تأییدشده، میانگین سبد، نمودار ماهانه، برترین برندها |

### افزودن محصول جدید
«محصولات → محصول جدید». فیلدهای «مشخصات فنی و سازگاری» به‌صورت خودکار بر اساس دستهٔ انتخابی تغییر می‌کنند
(مثلاً برای پردازنده: سوکت، تعداد هسته، TDP، نوع رم). همین فیلدها هستند که اسمبل هوشمند بر اساس آن‌ها
سازگاری را بررسی می‌کند؛ پس برای پردازنده `socket` و `tdp`، برای مادربرد `socket`/`ramType`/`formFactor`،
برای رم `ramType`، برای کولر `sockets` و `tdp`، برای کیس `formFactors`/`maxVga`/`maxCooler` و برای پاور
`wattage` را حتماً پر کنید.

## ۵) اسمبل هوشمند چطور کار می‌کند؟

1. پردازنده را انتخاب کنید.
2. مراحل بعدی فقط قطعات سازگار را نشان می‌دهند: مادربرد هم‌سوکت، رم هم‌نوع (DDR4/DDR5)، کولر با سوکت و توان کافی، کیس با فرم‌فاکتور و فضای کافی، پاور با توان کافی.
3. در پنل کنار، قیمت نهایی، توان مصرفی و فهرست بررسی‌ها را می‌بینید.
4. اگر ناسازگاری سخت‌افزاری باشد، دکمهٔ «افزودن به سبد» غیرفعال می‌ماند.
5. دکمهٔ «لینک» آدرس سیستم را کپی می‌کند تا برای مشاور فنی یا مشتری ارسال شود.

## ۶) ثبت سفارش و پیگیری

- سفارش با فرم تسویه ثبت می‌شود و در `data/aht_orders.json` ذخیره می‌شود (بدون نیاز به توکن، با پاکسازی ورودی).
- کد پیگیری به شکل `AHT-XXXXXXXX` به مشتری نمایش داده می‌شود؛ در `track.html` وضعیت را می‌بیند.
- پرداخت به روش کارت‌به‌کارت است؛ شماره کارت در تنظیمات قابل تغییر است.
  (درگاه زرین‌پال در `config.php` آماده است اما در جریان فعلی استفاده نمی‌شود.)

## ۷) نکات امنیتی و نگهداری

- رمز مدیر و شمارهٔ ورود فقط در `config.php` هستند؛ آن فایل را از دسترس مستقیم وب خارج نگه دارید (خارج از `public_html` یا با همان `.htaccess`).
- از پوشهٔ `data/` و `uploads/` پشتیبان بگیرید (همهٔ محصولات، تنظیمات و سفارش‌ها همان‌جاست).
- توکن ورود مدیر ۷ روز اعتبار دارد؛ «خروج از حساب» آن را باطل می‌کند.
- برای تغییر رمز: مقدار `AHT_ADMIN_PASS_SHA256` و `AHT_ADMIN_PASS_BCRYPT` را با
  `sha256(pass)` و `password_hash(sha256(pass), PASSWORD_BCRYPT)` به‌روزرسانی کنید.

## ۸) تست محلی (اختیاری)

```bash
cd site
php -S localhost:8080          # سپس http://localhost:8080
```
توجه: بدون PHP (مثلاً باز کردن مستقیم فایل‌ها) سایت با داده‌های نمونه نمایش داده می‌شود ولی
ذخیرهٔ تغییرات و پنل مدیریت کار نمی‌کند.
